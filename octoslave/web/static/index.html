Configuration

Built-in backend keys (e-INFRA CZ, NVIDIA NIM) are read-only here — edit ~/.octoslave/config.json or use environment variables to change them. To use any other OpenAI-compatible API, add it as a custom provider below.

Remote hosts (SSH)

Run the agent's tools on a remote machine over SSH — bash and file operations execute on the host you configure here. Uses your system ssh (keys / ~/.ssh/config / agent). Pick Remote next to the working-directory selector to switch.
After connecting, pick the working folder with the Browse… button next to the working-directory selector — it navigates the remote host.

Custom Providers

Bring your own OpenAI-compatible endpoint (OpenAI, Together AI, Groq, a self-hosted vLLM, etc.). Once added it appears in the Provider dropdown alongside the built-in backends.
