Providers & models

Where the models come from. Pick one with Use; it becomes the Provider in the chat bar. Add any OpenAI-compatible endpoint (OpenAI, Groq, Together AI, a self-hosted vLLM…) as a custom provider.

Remote hosts

Run the agent's commands and file operations on another machine over SSH. OctoSlave uses your system ssh, so your keys, ~/.ssh/config and agent all apply. Switch a chat to a host with the Local / Remote toggle next to the working folder.

+ Add a remote host

Shell command run before each command on this host — renewing a ticket, loading a base module, setting a PATH. Saves the agent having to remember it, and its own output is discarded.

Once connected, choose the working folder with Browse… next to the working-folder picker in Chat. It browses the remote machine.

Tools (MCP)

Give the agent extra tools through Model Context Protocol servers: git, GitHub, a browser, databases, live documentation and more. Installed tools are available in Chat, Science and Autonomous Research.
